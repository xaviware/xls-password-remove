# Password Eliminator .XLS

**Password Eliminator .XLS** (also known as PWDRECXLS) is a specialized utility designed to recover or remove protection from Microsoft Excel files (.XLS). Developed by XaviWare Software, it provides a user-friendly interface to handle forgotten passwords in spreadsheets.

## Key Features

- **Excel Protection Removal**: Specifically designed to work with .XLS files.
- **Multilingual Support**: Includes interface translations for:
  - English
  - Spanish (Español)
  - Arabic
  - Bulgarian
  - Polish
  - Romanian
- **Shareware Model**: Distributed as "try-before-you-buy" software.
- **Easy Integration**: Built with Visual Basic 6 for compatible Windows environments.
- **Installer Included**: Generated using InnoSetup for a smooth installation experience.

## Technical Details

- **Language**: Visual Basic 6 (VB6)
- **Deployment**: InnoSetup Script included
- **Configuration**: Uses `.lng` files for localization and `config.cfg` for settings.
